# Hello World 🌍

Hey there! 👋

Welcome to my very first blog post — and yes, this one is special! 🎉

I’ve just set up my **first blog** using the powerful features of **SvelteKit**, and I’m really excited to share what I’ve built.

This blog was made using:

- 🧰 **SvelteKit's built-in features**
    
- 📝 **MDsveX** to render markdown beautifully in Svelte
    
- 📓 **Obsidian**, my favorite notetaking app and markdown editor, along with a few helpful plugins
    

It’s been a fun journey connecting these tools together. With this setup, I can write and manage content in Obsidian (which I already use for note-taking), and publish it directly to my blog — no extra steps needed.

In my upcoming post, I’ll break down exactly how I set all of this up — including how I integrated Obsidian with SvelteKit and used MDsveX to power this markdown-driven blog.

Thanks for reading, and stay tuned for the technical deep dive! 🚀
